## 📌 Project Overview

**BWP** is a web-based esports tournament management platform designed to simplify the organization, execution, and tracking of competitive gaming events. The system aims to automate bracket generation, streamline team/player registrations, provide real-time score updates, and deliver a smooth experience for both players and tournament admins.

---

## 🎯 Target Goals & Key Features

* **🏆 Tournament Lifecycle Management**: Support for single-elimination, double-elimination, round-robin, and Swiss-style tournament brackets.
* **👥 Team & Player Profiles**: Registration, roster verification, and player career stats.
* **📅 Automated Scheduling & Matchmaking**: Instant fixture generation with dispute resolution tools for match referees.
* **📊 Live Brackets & Scores**: Real-time bracket visualization and score feeds via WebSockets.
* **🔔 Discord & Notification Integration**: Automated match check-ins, time reminders, and score updates.

---

## 🛠️ Proposed Tech Stack (Under Evaluation)

### Frontend
* **Framework**: React.js / Next.js
* **UI & Styling**: Tailwind CSS / Chakra UI
* **State Management**: Redux Toolkit / Zustand

### Backend & Database
* **API Framework**: Node.js (Express / NestJS) or Python (FastAPI)
* **Real-Time Layer**: Socket.io / WebSockets
* **Database**: PostgreSQL (Relational data) & Redis (Caching / Real-time sessions)
* **Auth & Integrations**: OAuth 2.0 (Discord & Steam Login)
